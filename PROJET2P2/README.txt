commande pour lancer le programme : python3 main.py arg1 arg2 arg3 "arg4"

arg1 est le nbr d'agent dans la simulation
arg2 est le gain de la couleur R 
arg3 est le gain de la couleur B
arg4 est optionnel. il permet d'avoir plus ou moins de détail dans l'affichage.
	-v pour afficher à chaque tour l"ordre des agents dans la liste.
	-vv Pour afficher quelle couleur ils portent, toujours dans l'ordre dans lequel ils se trouvent.
